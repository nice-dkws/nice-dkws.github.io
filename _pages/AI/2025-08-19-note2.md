### Summary
1. Excel에서 copilot 함수를 지원합니다.
   - =copilot(프롬프트, 참조) 의 형태로 사용 (자연어로 명령어를 넣으면 작업 진행)
	   - 예) =COPILOT("Classify this feedback", D4:D18) → 후기 감정 분석 / 그 외 설문조사, 데이터 요약 등도 사용 가능
   - 해당 함수로 데이터를 분석할 때 데이터는 AI 학습 등에 사용되지 않음 (요청 작업 수행하는데만 사용)
   - Windows: Version 2509 (Build 19212.20000) 버전부터 사용 가능 (Microsoft 365 버전이네요...)

2. 오픈AI가 GPT-5용 프롬프트 최적화 도구를 공개하였습니다.
   - 기존 프롬프트를 붙여넣으면 자동으로 변환이 진행되며, 메모리 사용량, 실행시간 모두 개선되는 것이 확인되었습니다.
	   - [링크](https://platform.openai.com/)
   - 추가로 프롬프트 가이드도 공유되었습니다. 
	   - [링크](https://cookbook.openai.com/examples/gpt-5/gpt-5_prompting_guide)
   * reasoning_effort로 탐색, 도구 호출 강도를 조절하거나, Thinking depth를 지정하는 방식으로 효율을 높일 수 있음
